Demo backdrops · procedurales (sin IP)

Cuatro mesh gradients procedurales (puro CSS) que sirven como backdrop para previsualizar superficies Liquid Glass. El overlay de cristal abajo de cada tile muestra cómo se lee una toolbar a 0.55 alpha + 20 px blur sobre cada backdrop.

Nota: los wallpapers oficiales de macOS son propiedad de Apple y no se redistribuyen con este bundle. Estos cuatro backdrops procedurales son CC0 — úsalos para mocks o reemplázalos por tu propio asset en producción. Para wallpapers fotográficos reales, descárgalos de fuentes con licencia compatible (Unsplash, Pexels, NASA) o usa los oficiales de Apple bajo los términos que apliquen a tu proyecto.

Reglas de uso

  • El backdrop va en desktop / lockscreen — nunca como fill de un control.
  • No tileees, no recortes apretado, no apliques gradientes encima — las composiciones ya están balanceadas.
  • Cuando saques colores para el chrome, muestrea del extremo tonal opuesto del backdrop para que el Liquid Glass tenga contraste.
  • Para light mode prefiere Dawn / Ocean; para dark prefiere Aurora / Forest.
